# 기렌의 야망 (SS) 한글패치 v1.0.4

11월 23일 제보(#4)를 반영한 수정 릴리스입니다. 세이브 데이터는 그대로 쓰실 수 있습니다.

## 수정 (#4)

### 1. 엔딩 번역
- 엔딩 텍스트 21종(지구연방군·지온군·티탄즈·정통 지온군·네오 지온군·인류 멸망, 레빌·기렌 사망 엔딩 포함)이
  번역되지 않은 채 남아 있던 것을 모두 번역했습니다.
- 엔딩 글은 `ENDINGxx.MFD` 안의 280×960 그림(4bpp)으로 들어 있습니다. 원본 그림을 판독해 원문을 옮기고 직접 번역한 뒤,
  원본과 같은 줄 간격(약 21.8px)과 검은 외곽선으로 나눔스퀘어 네오로 다시 그렸습니다.

### 2. 계급 「상사」가 「사사」로 나오던 문제
- 계급 이름은 한자 16×12 글자 두 개를 조합해 그립니다. 한자 한 개에 한글 한 글자를 대응시켰는데, 「曹」는
  軍曹(중사)에서는 「사」, 曹長(상사)에서는 「상」이어야 해서 글자만 바꿔서는 둘을 동시에 맞출 수 없었습니다.
- 게임 코드(PROG01·PROG03)의 계급별 글자 선택 부분을 고쳐, 軍曹의 첫 글자는 이미 「중」으로 그려지는 中을 쓰게 하고,
  그래서 비는 「軍」 글자를 「상」으로 다시 그려 曹長의 첫 글자로 쓰게 했습니다.
  이제 하사·중사·상사·소위…대장이 모두 바르게 나옵니다.

### 3. 유닛 이름 표기
- 아가이 → 앗가이, 즈곡 → 즈고크(즈고크E·즈고크/C.A·즈고크-S형 포함), 족 → 족크, 고그 → 곡그, 하이고그 → 하이곡그
- 이름 끝의 「型」 글자가 한자로 남던 것을 「형」으로 바꿨습니다(구프-A형, 겔구그-S형, 자쿠Ⅱ-J형A, G육전형･A 등).
  자쿠Ⅱ 계열은 칸이 모자라 「･」를 뺐습니다(자쿠Ⅱ-C형･A → 자쿠Ⅱ-C형A).
- 목록 글자뿐 아니라 상세 화면 이름판과 병기 해설 제목도 같이 맞췄습니다.

## 검증

- 백그라운드 에뮬레이터로 전략 페이즈 → 인사 → 캐릭터 화면에서 계급 표시 확인(대장·소장·소령 등).
  曹長·軍曹 조합은 계급 코드를 임시로 바꿔 「상사」「중사」가 나오는 것을 확인했습니다.
- 게임 코드가 계급 글자를 고르는 경로를 중단점으로 추적해 확인했습니다(글자 번호 = 116 + 코드).
- 패치된 디스크에서 엔딩 21종 그림을 다시 꺼내 내용과 배치를 확인했습니다.
  (엔딩은 게임을 끝까지 진행해야 볼 수 있어 실제 엔딩 화면은 에뮬레이터로 확인하지 못했습니다.)
- 간편 적용 zip 으로 원본에 패치를 적용해 결과 SHA-256 일치 확인
