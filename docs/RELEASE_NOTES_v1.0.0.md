# 기렌의 야망 (SS) 한글패치 v1.0.0

세가새턴 **기동전사 건담 기렌의 야망**(T-13327G) 한글패치 첫 정식 릴리스입니다.

## 한글화 범위

- 이벤트 대사 3,661줄 — 원본처럼 줄 단위 그림 글자로 다시 그렸습니다.
- 도움말·메시지 창 132개, 세이브(백업 RAM) 안내
- 메뉴·명령·보고·병기·인물·거점 이름 — 게임에 한글 글꼴 출력 코드를 추가했습니다.
- 인물·병기 이름판, 병기 백과 122개
- 전략 화면 라벨·버튼, 페이즈 제목 5개(전략 / 행동 설정 / 공격 실행 / 국지전 / 적 사고 페이즈)
- 전체 맵 틀(부대 표시, 거점 표시, L-지상 / R-우주 / START-전환)
- 생산 도크 화면(도크, 자금, 자원, 병기명, 기수, 기간, 차량, 항공, 우주, 함선, 종료)
- 이벤트 동영상 한글 자막 321개

## 알려진 한계

- 생산 도크 화면과 공격 실행·국지전·적 사고 페이즈 제목은 빌드 검사만 통과했고, 실제 플레이 화면에서는 아직 확인하지 못했습니다.
- 그림 글자로 남은 일본어를 발견하시면 스크린샷과 함께 Issues 에 남겨 주세요.
