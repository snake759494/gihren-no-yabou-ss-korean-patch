# 기렌의 야망 (SS) 한글패치 v1.0.1

11월 1일 제보(#1)를 반영한 수정 릴리스입니다. 세이브 데이터는 그대로 쓰실 수 있습니다.

## 수정 (#1)

- **우주맵 화면 깨짐**: 우주맵 하단에 회색 줄 조각이 생기고, 일부 화면에서 그래픽이 겹쳐 보이던 문제를 고쳤습니다.
  원인은 동영상 한글 자막 코드였습니다.
  - 자막 코드를 끼워 둔 동영상 프레임 루틴이 동영상 밖(우주맵 등)에서도 실행되고 있었습니다.
    이때 원래 루틴이 호출한 쪽에 돌려주는 레지스터(r1~r7, MACH/MACL)를 자막 코드가 덮어써서
    게임이 원래 없던 스프라이트를 그렸습니다. 이제 자막 코드 앞뒤로 이 레지스터를 모두 보존합니다.
  - 자막 줄을 지울 때 VRAM을 0으로 채우던 것을 동영상의 검은색 값(0x80000000)으로 바꿨습니다.
    게임은 동영상이 남긴 이 값을 우주맵의 빈 칸 데이터로 그대로 다시 쓰기 때문에, 0으로 지우면
    빈 칸 자리에 0번 타일의 줄무늬가 보였습니다.
  - 자막이 있는 동영상이 재생 중일 때만 VRAM을 건드리도록 했습니다.
  - 일본판과 같은 입력으로 우주맵까지 진행해, VDP2 VRAM과 화면이 일본판과 일치하는 것을 확인했습니다.
- **세이브 버튼이 비활성처럼 회색으로 보임**: 전략 페이즈 메뉴의 「세이브」 글자를 흰색으로 고쳤습니다.
  원본 라벨에서 가장 많이 쓰인 색을 글자색으로 고르다 보니 「セーブ」 라벨만 그림자 색(회색)이 뽑혔습니다.
  메뉴·커맨드 라벨은 이제 모두 원본 글자색(가장 밝은 색)으로 그립니다.
- **개발 플랜의 「アト」**: 「アト 2 턴」으로 나오던 남은 기간 표시를 「남은 2 턴」으로 고쳤습니다.
  「ｱﾄ 」는 3바이트짜리 짧은 문자열이라 처음 문자열 추출에서 빠져 있었습니다. 이 문자열이 들어 있는
  두 프로그램 중 하나(PROG02)는 적재 주소가 달라 포인터를 찾지 못했는데, 이제 파일의 적재 주소로도 찾습니다.
