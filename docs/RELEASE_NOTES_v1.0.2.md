# 기렌의 야망 (SS) 한글패치 v1.0.2

11월 3일 제보(#2)를 반영한 수정 릴리스입니다. 세이브 데이터는 그대로 쓰실 수 있습니다.

## 수정 (#2)

- **우주맵 하단의 회색 줄 조각과 겹친 그래픽**: v1.0.1에서도 사이드 2 부근 우주맵의 헥스 아래에
  회색 줄 조각(16×4 스프라이트)이 남아 있던 문제를 고쳤습니다. v1.0.1에서 고친 자막 코드와는 별개의
  원인이었습니다.
  - 게임 데이터 압축(LZ) 스트림의 마지막 그룹을 해석하는 규칙이 잘못되어 있었습니다. 마지막 그룹의
    항목 수 바이트를 「항목 수 + 1」로 보고 끝의 2바이트를 패딩으로 버렸는데, 실제로는 게임이 그 2바이트까지
    항목으로 읽습니다. 그 항목은 대부분 반복(RLE) 항목이라서, 한글 문자열을 넣으려고 다시 압축한 모든 파일이
    끝부분 데이터를 잃고 있었습니다. 예를 들어 우주맵 데이터(GDATA00)는 끝의 342바이트가 빠졌고,
    이 때문에 우주맵에 원래 없던 스프라이트가 그려졌습니다.
  - 압축 해제·재압축 도구를 게임과 같은 규칙으로 고쳤습니다. 원본 디스크의 압축 스트림 1,918개 전부가
    새 규칙에서 정확히 스트림 끝까지 소비되는 것을 확인했습니다.
  - 이 수정으로 다시 압축되는 다른 파일(시나리오 대사, 맵 라벨 등)도 끝부분 데이터가 원본과 같아졌습니다.
  - 원인을 찾을 때는 패치 구성 요소를 나눠 빌드하며 범위를 좁혔습니다. GDATA00 하나만 같은 내용으로
    다시 압축해도 증상이 재현되는 것을 확인한 다음, 게임의 압축 해제 루틴(0x6031090)과 호출부를 추적했습니다.
