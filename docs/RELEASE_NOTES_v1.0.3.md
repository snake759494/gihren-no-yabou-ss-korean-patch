# 기렌의 야망 (SS) 한글패치 v1.0.3

11월 12일 제보(#3)를 반영한 수정 릴리스입니다. 세이브 데이터는 그대로 쓰실 수 있습니다.

## 수정 (#3) — 유닛 생산 화면

- **분류 메뉴의 초록 하이라이트**: 차량·항공·우주·함선·종료를 골랐을 때 하이라이트가 안 보이거나
  (차량·종료), 글자 대신 배경이 칠해지거나(항공), 글자보다 위로 어긋나던(우주·함선) 문제를 고쳤습니다.
  - 이 메뉴는 배경 그림에 어두운 글자가 박혀 있고, 선택된 줄에만 초록 글자 스프라이트를 정확히 겹쳐
    그리는 방식입니다. 이전 버전은 이 스프라이트를 위치와 색 번호를 따로 정해 만들어서 배경 글자와 맞지
    않았습니다.
  - 이제 배경에 넣은 한글 글자의 픽셀을 그대로 따서, 원본 스프라이트와 같은 자리·같은 초록색으로 만듭니다.
    원본 스프라이트의 위치는 원본 배경 글자와 맞대어 측정했습니다.
- **열 제목 「자금」 깨짐**: 생산 화면 배경 그림(DATA01)을 다시 만들 때 8×8 셀의 번호를 새로 매겼는데,
  게임은 도크 번호·자금·자원 숫자를 정해진 셀 번호에 직접 써 넣습니다. 그 번호가 다른 그림에 배정되면서
  「자금」 글자 일부가 숫자 조각으로 덮였습니다.
  - 바뀌지 않은 자리는 원본 셀 번호를 그대로 쓰고, 글자가 바뀐 자리만 남는 셀에 담도록 고쳤습니다.
    셀 수도 원본과 같은 1,207개입니다.
  - 이 과정에서 패치 도구가 이 화면의 셀 번호를 한 칸 밀려 해석하던 것도 바로잡았습니다(맵 값 n = 셀 n/2).

## 검증

- 백그라운드 에뮬레이터로 전략 페이즈 → 행동 페이즈 → 자브로 → 생산 화면까지 진행
- MS·MA·차량·항공·우주·함선·종료를 차례로 선택해 각 줄의 초록 하이라이트가 글자에 정확히 겹치는 것을 확인
- 도크·자금·자원 표시와 열 제목(병기명·기수·자금·자원·기간)이 깨지지 않는 것을 확인
- 게임이 VRAM에 올린 셀·맵·팔레트가 패치 데이터와 일치하는 것을 확인
- 간편 적용 zip 으로 원본에 패치를 적용해 결과 SHA-256 일치 확인
