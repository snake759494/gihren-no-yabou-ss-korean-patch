# 기렌의 야망(SS) 한글패치 작업 계획

## 분석 결과
- 디스크: Track1 MODE1/2352(데이터) + Track2 오디오. 파일 접근은 GFS(파일명/디렉터리) 기반.
- MFD 컨테이너: `[count][offset...][마지막값]` + 엔트리 `[type u32][dest u32][data]`.
  type 0x01xxxxxx = 압축(`[0x1000][groups]` + 워드 플래그 LZ), 0 = 비압축.
- LZ(워드형, 0x6031090): 16비트 플래그 LSB부터, 1=리터럴 2바이트, 0=참조(b1>>4)+2 길이/12비트 거리, b1 상위 4비트 0이면 RLE(n+3).
- 대사: A/B/R/S/Z/T 장면 파일. 엔트리0=스크립트, 엔트리1=줄 단위 16×16 4bpp 글자 이미지 띠, 엔트리2=립싱크(CRI).
  고유 글리프 1,490개 → 판독표(glyph_labels.json)로 3,680줄 원문 복원(lines_ja.json).
- 도움말/MESSAGE: TMSG/HELP/GMSG 안의 4bpp 비트맵 창(104장).
- 전략 UI 라벨/명칭: 비트맵(조사 중).

## 단계
1. 도구: LZ 압축기, 장면 재패킹, MFD 재패킹, ISO 재구성(LBA 재배치, EDC/ECC).
2. 파이프라인 검증: R002(오프닝) 한글 → 에뮬레이터 확인.
3. 대사 번역(lines_ko.json) 및 렌더링(서울한강/나눔스퀘어 16px, 원본 글리프 스타일 모사).
4. 도움말 비트맵 번역/렌더링.
5. UI/명칭 비트맵 조사·번역.
6. 빌드, 실행 검증, xdelta, G드라이브 복사.
